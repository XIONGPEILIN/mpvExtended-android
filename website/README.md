This Next.js site presents mpv NAS Player's SMB, FTP and WebDAV features, screenshots, contributors and current GitHub downloads.

## Development

```bash
pnpm install
pnpm dev
pnpm type-check
pnpm build
```

## Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Biome
- Lucide icons

Release metadata and downloads come from [XIONGPEILIN/mpvExtended-android](https://github.com/XIONGPEILIN/mpvExtended-android).
