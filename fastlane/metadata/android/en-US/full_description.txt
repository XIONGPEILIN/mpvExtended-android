mpv NAS Player is a NAS-first Android media player powered by libmpv.

Browse and play videos directly from SMB, FTP and WebDAV servers. Saved connections, automatic reconnect, SMB keep-alive and a seekable local streaming proxy make long videos and multi-episode playback more reliable on phones and tablets.

NAS features:

* Native SMB, FTP and WebDAV browsing
* Automatic network-folder playlists and continuous playback
* Stable playback history and resume positions for network files
* Network subtitles, external subtitles and network thumbnails
* Remote file selection and deletion
* Reconnect and keep-alive handling for interrupted NAS sessions

Player features:

* Hardware and software decoding through libmpv
* Picture-in-picture and background playback
* Custom gestures and player controls
* Precise seeking, speed presets, AB loop and frame navigation
* Audio, subtitle and external track selection
* Anime4K shaders and advanced mpv configuration
* Material 3 interface with phone and tablet layouts
* Simplified Chinese localization

The app keeps the original application ID so existing users can upgrade without losing settings, network connections, playback history or playlists.

Privacy:

* No advertisements
* No trackers
* Fully open source
